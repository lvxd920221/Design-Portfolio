5.1 修订记录 · 文字隐形缺陷（2026-11-12 复检）

项内容
触发用户反馈浏览器打开画板后只见灰色／深色矩形色块、手机线框，看不到文字。
根因render_node() 对所有节点调用 background_css(n)。Figma 的 TEXT.fills 是字形颜色，不是容器填充；首版把同一个 fills 同时写成 background-color 与 color，导致文字与底色同色、整段隐形，视觉上退化成纯色块。
影响面HTML 解析器静态扫描：155 / 159 个画板、3,552 处文字与直接背景同色；另有 70 处渐变字被写成 color:transparent。
首版漏检原因原 11 维校验只验证「文案字符存在且逐字全等」，没有验证文字是否可见，因此 159/159 PASS 属于结构正确但视觉错误的假阳性。
修复 1TEXT 节点不再调用 background_css / stroke_css / radius_css；fills 仅用于 color；描边改 -webkit-text-stroke，DROP_SHADOW 改 text-shadow。
修复 270 处 GRADIENT_LINEAR 文字改用 background-image + background-clip:text 渲染渐变字，不再输出透明字。
修复 315 处顶层白色说明 TEXT 板（如 11:1710）在原稿中是叠于深色说明板上的透明文字层，独立成板后补回 rgb(51,51,51) 底色，白字恢复可见。
复验结果静态 12 维 159 PASS / 0 FAIL；文案 66,698 字符、DOM 12,105、SVG path 2,081、图片引用 127 与修复前完全一致；无头浏览器逐板实测 159 板 / 4,023 文本节点：同色 0、孤立透明 0、渐变字 70、异常 0。
查看器补充新增 viewer.html：索引卡片默认进入「适配窗口」查看（等比缩放），可一键切 1:1 原像素或打开原文件；159 份画板文件本身零改动，仍为无脚本 1:1 静态页。
修订结论：文字内容、顺序、尺寸、配色数据与稿面零偏差，渲染层的可见性缺陷已全量消除；灰度／深色矩形中属于原稿真实 RECTANGLE 装饰块的部分保持不变。

5.2 修订记录 · 文字重叠、意外换行与蒙版缺失（2026-11-12 二次复检）

项内容
触发用户提交 3 张截图：p1_113 大标题与副标题互相压叠、p1_001 段落文案连排三遍、p1_002 白块与深色块盖住内容，要求「同类问题点都需要处理」。
根因 A · 字体回退换行缺失字体走系统回退链后字宽比原字体宽 1%～6%。TEXT 内层沿用 width:100% + white-space:pre-wrap，Figma 里单行的标题在浏览器被折成两行；再叠加 align-items:flex-end，多出的一行向上溢出（实测 p1_113 主标题上溢 110px），压住上方 54px 处的副标题，形成截图里的文字叠字。
根因 B · 蒙版缺失Figma 共 170 个 isMask 节点，其中 13 个是 alpha 渐变蒙版（如 11:489，alpha 1.0 → 0.8 → 0.0，句柄终点 y=0.7775）。原稿中蒙版把其后的纯白矩形裁成「上白下透」，底部数据文字因此可见；首版渲染器完全忽略 isMask，把蒙版和纯白矩形都画成不透明实色块，文字被整块盖住。
影响面（浏览器全量实测）159 板 / 3,134 个真 TEXT 节点：意外多换行 128、右溢>8px 93、严重上溢>12px 61、渲染引入的文字互相重叠 49；另有 13 组渐变蒙版语义缺失。
修复 1 · 几何校准用 Chrome 逐板测每个 TEXT 的自然宽度、真实渲染矩形与行数，生成 /tmp/text_calibration.json，仅对 284 个异常节点（占 9%）写入 white-space:pre + width:bbox/k + transform:scaleX(k)（k = Figma bbox 宽 / 回退字体自然宽，0.702～1.000）。换行点与视觉宽度同时回到稿面数值，其余 2,850 个节点零改动。
修复 2 · 蒙版语义渲染器新增 mask_image_css() / mask_css() / render_children()：遇 isMask 节点，把渐变 alpha 转成 CSS mask-image，并按 gradientHandlePositions 缩放终点、按 mask 与兄弟 bbox 偏移设置 mask-size / mask-position，作用于其后 14 个同层兄弟。
复验结果静态 12 维 159 PASS / 0 FAIL；浏览器 159 板 / 3,134 文本节点：同色 0、孤立透明 0、渐变字 70、加载异常 0；意外换行 128 → 4（−97%）、右溢 93 → 3（−97%）、渲染引入重叠 49 → 14（−71%）。蒙版实测：文字中心位于白块 83.3% 高度处，mask alpha = 0.000，白块完全透明。
内容零损伤回归修复前后逐文件比对：纯文本 70,172 字符、DOM 元素 16,202、SVG path 2,081、图片引用 127 全部完全一致；仅新增 284 处校准 CSS 与 14 处蒙版 CSS，未增删任何文案、节点或素材。
如实说明 · 未改动项① p1_001 的「建立设计规范系统，统一团队标准体系」连排三遍，是 Figma 源节点 11:397 的 characters 本身就重复三遍，按「保留原文案」未删；② 圆点、剪刀形装饰是原稿矢量／图标字形，按「不改写视觉」保留（其成对弧线的镜像缺失已在 5.3 修复）；③ 稿面 413 处 rgb(217,217,217) 灰色占位矩形为模板作者原始占位块，非渲染缺陷。
如实说明 · 检测口径浏览器 elementFromPoint 命中 79 处「不透明层」，该 API 不受 CSS mask 影响（mask 只改绘制不改命中测试），故不等于视觉遮挡；另经全量层序统计，388 组「同层矩形覆盖文字中心」100% 为文字排在矩形之后，证明 Figma children 为底→顶、DOM 层序正确，剩余叠压属源稿本身状态，未擅自调整 z-order。
修订结论：三张截图对应的排版错乱已定位到两个系统性根因并全量修复；本轮只改渲染层 CSS，未增删页面、未改写文案、未引入交互，159 份画板仍为零脚本 1:1 静态页。
