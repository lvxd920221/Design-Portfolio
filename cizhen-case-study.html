02 / 定位

一句话说清这个作品

作品面向 HR 与面试官：重点不是界面画了多少张，而是在强约束下做了哪些讲得清依据的判断。

我为一款双通道医疗设备，从 0 到 1 设计了一套 18 屏的触控交互系统——在医学文案不可改、安全必须前置、两路治疗要并行的强约束下，把"治疗师能不能安全、高效地完成一次治疗"，拆成一组可复用、可验收的界面规则。

03 / 背景

真实场景与三条硬约束

约束不是障碍，是我设计的起点。

这是一款面向医疗机构的双通道物理治疗设备，可同时对患者施加"磁振"与"磁电"两路治疗。设备形态较新，操作界面没有成熟范式可照搬。

治疗师站在床旁一体机前，要在有限步骤内完成身份确认、建档选患者、设置双通道参数、执行并监控治疗、最后归档记录。一次治疗有固定时长，过程中要能随时看清"哪一路在治、治的是谁、还剩多久"。

角色画像来自界面功能的反向归纳：临床操作者负责患者管理与双通道执行；评估查阅者回看档案与评估时间线；设备管理者通过密码进入次数设置。场景依据是床旁一体机、固定治疗时长、站立操作与强光诊室——这是从界面稿可见事实推出的使用场景，不是访谈结论。

约束是给定的，解法是我设计的。
01
医学文案由产品资料给定

设备原理、治疗范围、禁忌症条目我无权改写，设计价值放在结构与可读性上。

02
安全确认必须发生在治疗开始之前

交互顺序服务于安全，效率要让位；漏确认的代价高于多一次点击。

03
磁振 + 磁电两路并行且各自独立

界面必须让两路状态同时可见、互不混淆，任一路变化不改变另一路的阅读位置。

04 / 职责

我负责什么，产品给定什么

边界划清，才显专业。我的价值不在于把屏幕做满，而在于把不可动摇的约束翻译成治疗师能快速、准确执行的操作路径。

医学内容设备原理、治疗范围、禁忌症原文
我设计并交付信息层级重组、分组、确认时机设计
业务流程登记 → 评估 → 治疗 → 归档
我设计并交付收束为不被打断的直线路径、定义页面状态
双通道磁振 + 磁电两路并行
我设计并交付对等分卡结构、三重状态编码、歧义消除
安全告知禁忌症、中断须确认的节点
我设计并交付用模态而非提示条的交互取舍
品牌文案"仁济天下 惠达众生"等
我设计并交付视觉呈现、双语标签体系、色彩语义分工
组件系统—
我设计并交付筛选 / 表格 / 分页 / 弹窗的跨域复用规范

项目交付物为界面设计稿与规范说明；起止日期、团队编制及研发还原、注册评审由对应团队负责。

05 / 决策

七个关键决策

每条按「冲突 → 备选 → 选择 → 依据」展开。这是最能体现设计判断力的部分。

冲突两路并行，操作者可能在未确认"当前是哪一路"时就暂停或调参。
备选A 单一面板 + 通道切换 Tab；B 上下 / 左右对等双卡。
选择B——两卡结构、字号、间距、控件顺序严格一致。
依据合并面板强制多一次"当前选中哪一路"的判断，而这个二次判断正是错误源。我用空间换确定性——空间是可控成本，误操作不是。
冲突禁忌症确认要打断治疗前的流程。
备选A 页面内提示条 + 勾选；B 居中模态 + 遮罩锁定背景。
选择B——"重要安全警告""治疗未结束"都做成必须选择的模态。
依据提示条允许"边读边操作"，而禁忌症确认必须精确发生在治疗开始之前这一个时间点。我用一次确认动作，换取确认行为不可跳过。
冲突诊室强光、操作者远近切换，单一颜色状态不可靠。
备选A 仅用状态色；B 色点 + 状态文字 + 按钮可用性。
选择B——"未开始/治疗中"同时由圆点、文字、按钮是否可用三处表达。
依据我不想让单一色彩承载全部信息。冗余编码让状态在任何光线下都能被读懂，这是可用性上的基本判断。
冲突"当前治疗对象是谁"若不明确，可能张冠李戴。
备选A 始终显示下拉选择；B 未选态只给"添加 / 选择"，已选态回显头像、姓名、性别年龄、掩码电话。
选择B。
依据把治疗对象做成常驻可见信息，是避免错配的最低成本手段；掩码电话是我对患者隐私的主动处理。
冲突建档字段多，填表负担重，但不能删字段。
备选A 单列滚动；B "01 基本信息 / 02 病情评估"等宽双栏。
选择B——必填红星前置、下拉收窄输入、标签多选、就地校验。
依据编号把长表单切成两个可完成的小任务，降低"还有多少要填"的未知感。我的目标不是删字段，而是把"填表"变成"核对"。
冲突新增记录界面，是否要另起一套设计。
备选A 为治疗记录单独设计表格；B 复用四维筛选 / 表格 / 分页 / 行操作。
选择B——只替换字段语义（患者 / 治疗类型 / 起止时间 / 时长）。
依据同一套组件贯穿患者管理与治疗记录，新增界面不再产生新的学习成本。这是我刻意把组件复用当作设计决策、而非实现便利的原因。
冲突产品资料原文偏长，按 UI 习惯精简会更好看。
备选A 通俗化改写；B 原文呈现，只处理结构与可读性。
选择B。
依据设备原理、治疗范围、禁忌症由产品资料给定，设计师不是医学内容的作者。我主动放弃"改写的权力"，把设计价值放在结构与可读性上——这是专业边界感。
06 / 流程

一条不被打断的治疗闭环

治疗前 → 治疗中 → 治疗后，九步串起建档、执行、归档。

治疗前 · 准备PHASE A

01设备密码登录，错误就地提示
02患者列表四维筛选与查询
03新建 / 编辑患者：编号双栏表单
04绑定当前治疗对象，回显身份

治疗中 · 执行PHASE B

05重要安全警告：禁忌症强制确认
06磁振 / 磁电双通道参数与启动
07倒计时监控与中断保护确认

治疗后 · 归档PHASE C

08结束治疗，状态归位
09记录汇总 / 个人视图追溯
旁路流程：待机页持续播报双路剩余时间与产品原理轮播；次数设置走「密码验证 → 设定次数」两级，与临床主流程不交叉。

    重要安全警告

    请在开始治疗前确认以下禁忌症条目。原文由产品资料给定，界面只做层级与可读性处理；此处按修订单 T1 放大字号并加粗关键词。

    1. 颈动脉、颅脑和心脏部位禁止直接治疗。
    2. 体内植入心脏起搏器者禁止使用。
    3. 妊娠、孕妇腹部及腰骶部禁止使用。
    4. 出血倾向、急性感染或发热期患者应评估后使用。
    5. 恶性肿瘤局部区域禁止直接治疗。
    6. 治疗部位有金属植入物或破损皮肤时应避开。

    治疗未结束

    治疗疗程正在进行中，是否停止治疗？中断操作必须二次确认，避免一次误触终止疗程。
