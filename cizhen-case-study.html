02 / POSITIONING

不是画完 18 张屏幕，
而是建立一套可执行的界面规则。

这页先回答面试官最关心的三个问题：项目解决什么问题、设计师承担什么、哪些设计判断有证据支撑。

约束是给定的，
解法是我设计的。

项目价值不靠未经验证的业务增长数字支撑，而由完整界面覆盖、交互规则、界面实测和组件复用证据构成。

01

医学文案不能随意改写

设备原理、治疗范围、禁忌症由产品资料给定。设计工作放在内容分组、信息层级和可读性上。

02

安全确认必须发生在治疗之前

禁忌症与中断确认不能被普通提示替代；关键确认要发生在准确的操作节点。

03

磁振与磁电两路并行、各自独立

界面必须让两路状态同时可见，任一路变化不应改变另一路的阅读位置和操作预期。

DESIGN GOAL 01

状态可判断

用颜色、文字和控件可用性共同表达状态，不把含义押在单一色彩上。

DESIGN GOAL 02

安全可拦截

把禁忌症确认和未结束中断设计成有明确动作后果的模态流程。

DESIGN GOAL 03

组件可复用

患者管理与治疗记录共用筛选、表格、分页和行操作组件。

03 / CONTEXT

先看清真实场景，
再决定信息应该如何出现。

用场景约束解释界面结构，而不是堆用户画像和未经验证的调研结论。

A

身份确认

治疗开始前必须知道“正在治疗谁”。选择后，患者姓名、性别年龄与掩码手机号常驻回显。

B

治疗执行

磁振与磁电两路同时存在，各自拥有独立状态、倒计时与控制按钮。

C

中断保护

治疗未结束时点击停止，先进入二次确认，避免一次误触直接终止疗程。

04 / MY ROLE

把产品给定的边界，
转译成设计师负责的规则。

明确哪些是原始业务约束，哪些是你做出的设计决定。这比笼统写“负责全流程 UI”更可信。

产品给定 / GIVEN

INPUTS
  • MEDICAL CONTENT设备原理、治疗范围、禁忌症原文
  • BUSINESS FLOW登记 → 评估 → 治疗 → 归档
  • DUAL CHANNEL磁振 + 磁电两路并行
  • SAFETY RULES禁忌症与中断确认节点
  • BRAND LANGUAGE“仁济天下 惠达众生”等品牌文案

我设计并交付 / DESIGN

OUTPUTS
  • INFORMATION信息层级、内容分组与确认时机
  • INTERACTION直线路径、页面状态与双通道交互
  • VISUAL SYSTEM视觉呈现、双语标签、色彩语义分工
  • SAFETY UX以模态确认代替普通提示条
  • COMPONENTS筛选 / 表格 / 分页 / 弹窗跨域复用规范

交付物为界面设计稿与规范说明。起止日期、团队编制、研发还原与注册评审由对应团队负责；本案例不将其写成个人交付成果。

05 / DESIGN DECISIONS

七个关键决策。
每一个选择，都有明确的取舍依据。

前三个高影响决策配真实界面大图；其余四个保留完整逻辑，收进可展开的决策清单。

D01 · DUAL-CHANNEL STRUCTURE

双通道用对等分卡，
不用合并面板。

冲突
两路并行，操作者可能在未确认当前通道时暂停或调参。
备选
A 单一面板 + 通道切换 Tab；B 上下 / 左右对等双卡。
选择
B：两卡结构、字号、间距与控件顺序严格一致。
依据
合并面板会额外引入“当前选中哪一路”的判断。我用空间换确定性。
D02 · SAFETY FIRST

安全告知用模态，
不用普通提示条。

冲突
禁忌症确认必须在治疗开始前发生，提示条允许用户边读边操作。
备选
A 页面内提示条 + 勾选；B 居中模态 + 遮罩锁定背景。
选择
B：重要安全警告与治疗未结束均使用必须选择的模态。
依据
把关键确认固定在正确时点，避免确认动作被跳过。
D03 · STATE ENCODING

状态使用三重编码，
不只依赖颜色。

冲突
诊室强光、操作者远近变化时，单一颜色状态并不可靠。
备选
A 仅用状态色；B 色点 + 状态文字 + 按钮可用性。
选择
B：未开始 / 治疗中由圆点、文字和控件可用性共同表达。
依据
冗余编码减少单一视觉线索失效时的误读风险。

未选态只提供“添加 / 选择”；已选态回显头像、姓名、性别年龄和掩码电话。常驻显示治疗对象，避免错配。

以“01 基本信息 / 02 病情评估”分区；必填项前置、下拉收窄输入、标签多选、就地校验。目标不是删字段，而是把填表变成核对。

复用四维筛选、表格、分页与行操作，只替换患者、治疗类型、起止时间和时长等字段语义。

设备原理、治疗范围和禁忌症来自产品资料。设计价值放在结构、层级与可读性，不擅自修改医学含义。

06 / USER FLOW

一条不被打断的治疗闭环。

把九个关键步骤放到同一条时间线上，让人先理解系统，再看单张界面。

治疗前 · 准备

PHASE A
  1. 01设备密码登录，错误就地提示
  2. 02患者列表四维筛选与查询
  3. 03新建 / 编辑患者：编号双栏表单
  4. 04绑定当前治疗对象，回显身份

治疗中 · 执行

PHASE B
  1. 05重要安全警告：禁忌症强制确认
  2. 06磁振 / 磁电双通道参数与启动
  3. 07倒计时监控与中断保护确认

治疗后 · 归档

PHASE C
  1. 08结束治疗，状态归位
  2. 09记录汇总 / 个人视图追溯
旁路流程：待机页持续播报双路剩余时间与产品原理轮播；次数设置走“密码验证 → 设定次数”两级，与临床主流程不交叉。

主视觉优先展示治疗主界面；下面保留全部 18 张原始界面稿，支持分组筛选、搜索和放大查看。

10 / TAKEAWAY

把复杂操作，
变成清楚的规则。

这套设计的重点不是增加视觉装饰，而是让治疗对象、双通道状态、安全确认和操作结果在关键时刻都能被准确理解。
